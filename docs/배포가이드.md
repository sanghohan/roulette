# 배포 가이드 — donjiral 메뉴 룰렛

흐름: **소스를 GitHub에 푸시 → 정적 호스팅에 올림 → 카페24 도메인(www.donjiral.net) 연결**

---

## 1. GitHub에 푸시

저장소(이미 생성됨): https://github.com/sanghohan/roulette

이 폴더에서 아래를 실행하세요(맥/터미널 기준). git 커밋은 이미 만들어져 있으니 원격만 연결해 올리면 됩니다.

```bash
cd roulette-site
git remote add origin https://github.com/sanghohan/roulette.git
git branch -M main
git push -u origin main
```

- 처음 푸시 때 GitHub 로그인(또는 토큰)을 요구합니다.
  비밀번호 대신 **Personal Access Token**이 필요해요: GitHub → Settings → Developer settings → Personal access tokens → 생성 후 비밀번호 칸에 붙여넣기.
- 이미 `origin` 이 등록돼 있다면 `git remote set-url origin ...` 으로 바꾸세요.

## 2. 호스팅 선택

정적 사이트(HTML 한 장)라 어디든 가볍게 올라갑니다.

### 옵션 A. AWS S3 + CloudFront  (말씀하신 AWS 구성)
1. **S3 버킷 생성** (이름 예: `donjiral-roulette`), 정적 웹사이트 호스팅 활성화, 인덱스 문서 `index.html`
2. 파일 업로드 (루트의 `index.html`, `roulette/` 폴더 통째로)
   ```bash
   aws s3 sync . s3://donjiral-roulette --exclude ".git/*" --exclude "docs/*"
   ```
   → `/roulette` 경로는 `roulette/index.html` 이 자동으로 잡힙니다.
3. **CloudFront 배포 생성** — 오리진을 S3로, 기본 루트 객체 `index.html`, HTTPS 적용
4. **ACM(인증서)** 에서 `www.donjiral.net` 인증서 발급(버지니아 us-east-1 리전) 후 CloudFront에 연결
5. CloudFront 도메인(`xxxx.cloudfront.net`)을 메모 → 3단계 도메인 연결에 사용

> /roulette 처럼 하위 경로의 새로고침이 404가 나면, CloudFront의 "사용자 정의 오류 응답"에서 404 → `/index.html`(200) 매핑을 추가하거나, S3에 `roulette/index.html` 이 있는지 확인하세요(이 저장소엔 포함돼 있음).

### 옵션 B. (가장 쉬움) GitHub Pages / Netlify / Vercel
- GitHub Pages: 저장소 Settings → Pages → Source `main` 브랜치 → 즉시 배포. 무료·HTTPS 자동.
- Netlify/Vercel: GitHub 저장소 연결 한 번이면 끝. 커스텀 도메인 입력란에 `www.donjiral.net` 추가.

AWS 비용·운영이 부담되면 B로 시작했다가 나중에 AWS로 옮겨도 됩니다.

## 3. 카페24 도메인(www.donjiral.net) 연결

카페24 **도메인 관리 → DNS 관리(네임서버/레코드 설정)** 에서:

- **CloudFront(옵션 A)** 또는 Netlify/Vercel/GitHub Pages를 쓸 경우:
  `www` 호스트에 대해 **CNAME** 레코드를 호스팅이 알려준 주소로 지정
  ```
  유형: CNAME
  호스트: www
  값: (예) xxxx.cloudfront.net  또는  your-site.netlify.app
  ```
- 루트 도메인(`donjiral.net`, www 없는 주소)도 쓰려면 카페24의 **URL 포워딩** 또는 ANAME/ALIAS 기능으로 `www.donjiral.net` 으로 연결하세요(루트는 CNAME을 직접 못 거는 경우가 많음).

DNS 반영에는 수 분~수 시간이 걸릴 수 있습니다.

---

## 정리
1. `git push` 로 소스 업로드
2. 호스팅(AWS S3+CloudFront 권장, 또는 GitHub Pages)에 배포
3. 카페24 DNS에서 `www` → 호스팅 주소 CNAME 연결
4. 완료 후 https://www.donjiral.net 과 https://www.donjiral.net/roulette 모두 접속 확인
5. 앱 ⚙️ 연결 탭에서 Supabase 정보 입력 → 실시간 공유 활성화
