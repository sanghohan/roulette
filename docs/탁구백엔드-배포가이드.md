# 탁구 커뮤니티 백엔드 배포 가이드 (Kotlin + Spring Boot, Docker)

구성: **프론트(GitHub Pages, https://www.donjiral.net) ↔ 백엔드(AWS EC2, Docker)**
DB: 기본 **H2 파일 모드(무료, 추가 인프라 0)**. 나중에 PostgreSQL로 전환 가능.

> ⚠️ 중요: 프론트가 https라서 **백엔드도 반드시 https**여야 브라우저가 호출을 허용합니다(mixed content 차단). 그래서 아래에서 Caddy로 자동 HTTPS를 붙입니다.

## 1. EC2 인스턴스 생성 (프리 티어)
1. AWS 콘솔 → EC2 → **인스턴스 시작**
2. AMI: **Amazon Linux 2023**, 타입: **t2.micro 또는 t3.micro (프리 티어)**
3. 키 페어 생성/선택(SSH 접속용 .pem)
4. **보안 그룹** 인바운드 규칙:
   - SSH (22) — 내 IP
   - HTTP (80) — 0.0.0.0/0
   - HTTPS (443) — 0.0.0.0/0
5. 시작 후 **퍼블릭 IP** 메모

## 2. 도메인 연결 (카페24 DNS)
백엔드용 서브도메인을 EC2로 연결합니다.
```
유형: A
호스트: api
값: (EC2 퍼블릭 IP)
```
→ `api.donjiral.net` 이 EC2를 가리킵니다. (반영에 수 분~수 시간)

> 고정 IP가 필요하면 EC2 **탄력적 IP(Elastic IP)**를 할당해 연결하세요(인스턴스 1개에 붙여두면 무료).

## 3. EC2에 접속 & Docker 설치
```bash
ssh -i your-key.pem ec2-user@api.donjiral.net

# Docker 설치
sudo dnf update -y
sudo dnf install -y docker git
sudo systemctl enable --now docker
sudo usermod -aG docker ec2-user
# docker compose 플러그인
sudo mkdir -p /usr/local/lib/docker/cli-plugins
sudo curl -SL https://github.com/docker/compose/releases/latest/download/docker-compose-linux-x86_64 \
  -o /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose
# 그룹 적용 위해 재로그인
exit
```
다시 접속:
```bash
ssh -i your-key.pem ec2-user@api.donjiral.net
docker --version && docker compose version
```

## 4. 소스 받아서 실행
```bash
git clone https://github.com/sanghohan/roulette.git
cd roulette/backend
docker compose up -d --build      # 첫 빌드는 몇 분 걸립니다
docker compose logs -f            # 로그 확인 (Ctrl+C로 빠져나옴)
curl http://localhost:8080/api/health
```
여기까지면 EC2 안에서 8080으로 API가 떠 있습니다. (아직 http, 외부에선 https 필요)

## 5. 자동 HTTPS 붙이기 (Caddy 리버스 프록시)
가장 간단한 방법. Caddy가 Let's Encrypt 인증서를 자동 발급/갱신합니다.

`roulette/backend/` 에서:
```bash
# Caddyfile 생성
cat > Caddyfile <<'EOF'
api.donjiral.net {
    reverse_proxy api:8080
}
EOF
```
`docker-compose.yml`에 caddy 서비스를 추가하거나, 아래 별도 명령으로 실행:
```bash
docker network create web 2>/dev/null
# api 컨테이너를 web 네트워크에 연결되도록 compose에 network 추가하거나,
# 간단히 호스트 포트로 프록시:
docker run -d --name caddy --restart unless-stopped \
  --network host \
  -v $(pwd)/Caddyfile:/etc/caddy/Caddyfile \
  -v caddy_data:/data \
  caddy:2
```
> `--network host` + Caddyfile의 `reverse_proxy localhost:8080` 조합이 가장 단순합니다. 이 경우 Caddyfile의 `api:8080`을 `localhost:8080`으로 바꾸세요.

확인:
```bash
curl https://api.donjiral.net/api/health   # {"status":"ok"}
```

## 6. 프론트엔드를 서버에 연결
브라우저에서 https://www.donjiral.net/pingpong/ 접속 후, 개발자 콘솔(F12)에서:
```js
localStorage.setItem('pingpong_api','https://api.donjiral.net');
location.reload();
```
상단 배너가 "✅ 서버 연결됨"으로 바뀌면 완료. 이제 글/댓글이 모두에게 공유됩니다.

> 모든 방문자에게 기본 적용하려면 `pingpong/index.html`의 `let API_BASE = "";` 를
> `let API_BASE = "https://api.donjiral.net";` 로 바꿔서 커밋·푸시하세요.

```bash
cd roulette/backend
git pull

```

## PostgreSQL로 전환하고 싶을 때
1. `docker-compose.yml`의 `db` 서비스 주석 해제, `api`에 `SPRING_PROFILES_ACTIVE=postgres` 등 환경변수 추가
2. `docker compose up -d --build`
3. 끝. JPA가 테이블을 자동 생성합니다(`ddl-auto: update`).

## 비용 메모
- EC2 t2.micro: 프리 티어 12개월간 월 750시간 무료(1대 상시 가동 가능)
- H2 파일 DB: 추가 비용 0 (EC2 디스크에 저장, `./data` 볼륨에 영속)
- 12개월 이후엔 t3.micro 기준 대략 월 수천 원대 — 가장 저렴한 상시 운영 구성
