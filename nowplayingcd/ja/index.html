💿 Now Playing CD

今聴いている曲を、あの頃のCDプレーヤーで。 · Android

YouTube Music などの音楽アプリで曲を再生すると、Now Playing CD がその曲を90年代のCDプレーヤーで表示します。 ジャケットが印刷されたCDが回り、アルバムが変わると新しいCDが入り、リモコンで音楽アプリを操作できます。 アプリを開くと、最後に使っていた音楽アプリで続きが再生されます。

Now Playing CD 自体は音楽を再生しません。音楽はいつもの音楽アプリがそのまま再生し、Now Playing CD はその曲を表示して操作します。

Google Play で入手

1. 初めての起動 — 音楽アプリと接続

  1. Now Playing CD を開き、「音楽アプリと接続」が表示されたら設定を開くをタップ。
  2. 通知へのアクセスで Now Playing CD をオンにして許可。
  3. Now Playing CD に戻れば準備完了です。

なぜ通知へのアクセスが必要? Android で他のアプリが何を再生しているか(曲名・ジャケット・再生位置)を知る方法はこの権限だけです。 Now Playing CD が読むのは再生情報だけで、通知の内容は読みません。

2. 音楽を再生する

  • 音楽アプリで曲を再生して戻ると、CDが入って回り始めます。
  • アルバムが変わると新しいCDが入ります。同じアルバムの次の曲なら、CDはそのまま回ります。
  • ジャケットはまず音楽アプリから受け取り、なければアルバム名で探します。見つからなければ虹色のCDになります。
  • 音楽アプリを開く必要はありません。Now Playing CD を開くと「▶ ○○で続きを再生します」と表示され、最後に聴いていたアプリで再生が始まります(メニュー → 設定 → 開いたらすぐ再生でオフにできます)。リモコンの ▶ でも同じです。別のアプリで聴くときはメニュー → 再生 → 音楽アプリから選んでください。

3. スキン

メニュー → 設定 → スキンでプレーヤーを選べます:教室(机の上のスロットイン式プレーヤー)またはバス(ふたが開閉するポータブルプレーヤー)。

液晶にはトラック番号、時間、「アーティスト - 曲名」が表示されます。READING は新しいCDを読み込み中という意味です。しばらく一時停止していると、時間の位置に時計が表示されます。

5. メニュー

右上の ⠿ ボタン(9つの点)をタップすると、右からメニューが出てきます。外側か ✕ をタップすると閉じます。スリープタイマー中は、ボタンの横に残り時間(分)が表示されます。

6. 画面・ロック・終了

  • アプリを開いている間は画面が消えません。机に置いておくのにぴったりです。ロック画面にもそのまま表示されます。
  • スマホでは縦画面です。開いた折りたたみスマホやタブレットは横向きにもできます。
  • アプリの言語はスマホの言語に合わせます:日本語、韓国語、スペイン語(1.9から)、それ以外は英語。
  • メニュー → 画面ロックで誤タッチを防ぎます。どこでも1秒長押しすると解除されます。
  • メニュー → 終了で音楽も一時停止してアプリを閉じます。

7. 困ったときは

曲が表示されない。通知へのアクセスで Now Playing CD がオンになっているか、音楽アプリで実際に再生しているか確認してください。アプリを更新するとアクセスがオフになることがあります。そのときは案内がもう一度表示されるので、設定を開くをタップしてください。

一度も使ったことのない音楽アプリが ▶ で再生されない。そのアプリで一度曲を再生してください(OPEN で開けます)。その後は ▶ で再生できます。

アラームが鳴らない。スマホの設定で、Now Playing CD のアラームとリマインダーが許可されているか確認してください。
